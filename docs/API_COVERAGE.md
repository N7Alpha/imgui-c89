# Frozen handwritten-prototype API and subsystem coverage

This checklist records the state of the original independent reimplementation.
That implementation is now non-normative and frozen for parity feature work.
Entries here may identify reusable tests or facade requirements, but they do
not measure coverage of the generated faithful core. Translator coverage is
tracked by construct fixtures, generated manifests, and the compatibility
matrix described in `DESIGN.md`.

Legend: `[ ]` unstarted, `[~]` scaffolded/incomplete, `[x]` parity tested.
